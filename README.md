# HemaCord – Blood Donation Camp Management System

HemaCord is a blood donation camp management platform designed to simplify donor management, organize blood donation camps, manage appointments, and display blood-group statistics.

## How to Run the Frontend Locally

### Prerequisites
- Node.js installed on your system.
- Visual Studio Code installed.

### 1. Clone the Repository

```bash
git clone https://github.com/PRIYAM9595/HemaCord-Blood-Donation-Camp-Management-System.git
```

### 2. Open the Project Folder

```bash
cd HemaCord-Blood-Donation-Camp-Management-System
```

Open this folder in VS Code.

### 3. Install Dependencies

Open the VS Code terminal and run:

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

After the server starts, open the local URL displayed in your terminal:

```text
http://localhost:5173/
```

The HemaCord frontend will now be running locally.

**Note:** These instructions are for running the frontend locally. Backend and database functionality require separate setup.
